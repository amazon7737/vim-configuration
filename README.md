## iTerm2 theme

- Theme file: `iterm2/Warm-Charcoal.itermcolors`

Apply in iTerm2:

1. Open iTerm2 Settings: `Cmd + ,`
2. Go to **Profiles → Colors**
3. Click **Color Presets… → Import…**
4. Select `iterm2/Warm-Charcoal.itermcolors`
5. Choose **Color Presets… → Warm-Charcoal**

Palette:
